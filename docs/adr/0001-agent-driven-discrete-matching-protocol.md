# 1. 采用基于双重证据的离散三态匹配语义协议与 Scope/Eligibility 解耦

日期: 2026-08-15

## 状态

已通过 (Accepted)

## 上下文与问题陈述

传统求职与职位匹配系统普遍采用基于关键词加权的连续数值打分（如 Match Score 85%）或庞大的硬编码 `if/else` 规则引擎。在面对高校专任教师与数字创意跨界岗位时存在两大核心缺陷：
1. **伪精确性与缺乏解释力**：连续打分无法向用户清晰解释 82 分与 78 分的具体差别，更无法准确反映中国高校体制内复杂的“专业代码准入 vs 实际课程讲授能力”的双轨要求；
2. **搜索范围与资格混淆**：若将用户地域偏好直接作为资格不符合（如将省外岗位算为 0 分或不合格），会导致数据模型污染，无法复用岗位本身的合规性判定结果。

## 决策

我们决定在 Career Radar 中**彻底摒弃连续数值打分（Match Score）**，确立**由 Agent 驱动的离散语义匹配决策协议**：

1. **Scope 与 Eligibility 严格解耦**：
   - `Scope`（`IN_SCOPE` / `OUT_OF_SCOPE`）表示用户检索偏好边界，超出范围仅代表不主动通知，不影响资格判断；
   - `Eligibility` 仅在 `IN_SCOPE` 机会中进行评估。
2. **双重证据模型与六大资格维度**：
   - 评估基于第一方公告凭证（Requirement Evidence）与候选人私有事实（Candidate Evidence），由 Agent 进行语义推理；
   - 包含 6 个核心维度（`Age`, `Education`, `Formal Qualification`, `Capability Fit`, `Teaching Experience`, `Industry Experience`），每个适用维度输出 5 种证据状态之一（`PASS`, `REVIEW`, `FAIL`, `UNKNOWN`, `N/A`）。
3. **正式专业代码与课程能力分离**：
   - 公办编制岗位严查 `Formal Qualification`；民办与产业岗位以 `Capability Fit` 为主。
4. **权威 Hard Blocker 熔断与 UNKNOWN 补查机制**：
   - 仅在第一方权威证据确凿且无放宽时才判定为 `FAIL`，触发 `明显不符合`；
   - 出现 `UNKNOWN` 时，Agent 拥有自主追查附件与权威公告的调查权，仅在查证未果后保留 `UNKNOWN` 并归入 `需要人工确认`。
5. **最终三态输出**：
   - 最终呈现为 `建议关注`、`需要人工确认`、`明显不符合` 三态，并输出维度证据展开、标签集与一句话可解释原因。

## 后果与权衡

### 积极影响
- **高可解释性**：每一条推荐机会都有明确的证据链支撑，用户能一眼看清为何推荐或为何需要人工确认；
- **低误杀率**：杜绝了因规则过于激进而遗漏边缘放宽机会的风险；
- **模型解耦**：资格判断与地域/赛道偏好彻底解耦，结构清晰。

### 潜在代价
- 依赖 Agent 的语义推理能力，对底层数据抽取（特别是附件文本提取）的质量要求较高。
