# ADR-0005: 资格准入 (Eligibility)、机会行动意图 (Opportunity Intent) 与个人偏好 (Preference) 的正交解耦

## 状态

**已通过 (Accepted)**

## 上下文

在职业雷达的早期模型中，存在将“候选人是否符合岗位资格门槛（Eligibility）”、“候选人对赛道与岗位的战略关注度（Preference / Priority）”以及“候选人面对具体岗位应采取的行动策略（Intent）”相互混淆的风险。

例如：
1. 候选人在法律与专业能力上完全符合某岗位准入门槛（`Eligibility: PASS / 建议关注`），但由于个人时间排期或地域权衡，当前并不打算立即投递，而应采取 `CONDITIONAL`（条件关注）；
2. 候选人符合某前沿岗位条件，但该岗位更适合作为跟踪技术与薪酬标杆的情报窗口，应采取 `WATCH_LEARN`（情报观测）；
3. 候选人设定的赛道具有高优先级（如 `Priority: 1`），但这绝不意味着该赛道下的每一个具体岗位都应当被无条件标记为立即申请；
4. 候选人被某高吸引力机会吸引，但这绝不能反向篡改客观硬门槛评估（`Eligibility: FAIL` 绝不能因为意图积极而变为 `PASS`）。

如果将偏好、资格与行动意图糅合在单一评分或单一标签中，会导致法定资格证据失真，策略调整与客观准入无法独立演进。

## 决策

我们决定将 **资格准入 (Eligibility)**、**个人偏好 (Preference)** 与 **机会行动意图 (Opportunity Intent)** 作为三个完全正交、独立演进的领域概念进行建模与管理：

1. **资格准入 (Eligibility)**：严格由 ADR-0001 规范（6 大客观维度、5 种证据状态、3 级推荐结论）所约束，仅衡量客观条件符合度。任何偏好考量均不得作为资格评估维度。
2. **个人偏好 (Preference)**：提供画像层级的检索路由与决策背景证据（如赛道优先级、保障诉求、雇佣形态、弹性薪酬考量与排期约束），作为 Agent 研判行动意图的输入上下文，绝不作为资格准入的阻断项。
3. **赛道默认意图 (Default Intent)**：在画像中作为赛道层级的初始行动倾向先验（Prior），供 Agent 决策参考，绝不机械等同于具体岗位的最终意图。
4. **机会行动意图 (Opportunity Intent)**：由 Agent 依据具体岗位条件与候选人偏好综合裁决的 3 态行动姿态（`APPLY_NOW` / `CONDITIONAL` / `WATCH_LEARN`），并附带独立理由（`intent_rationale`）。
5. **概念解耦关系**：公式上严格保持 `Track Priority != Default Intent != Opportunity Intent != Eligibility`。

## 后果

### 正面收益

- **证据客观纯粹**：客观资格准入评估不受个人主观意愿污染，保证证据链的真实性与合规性。
- **行动策略高度灵活**：支持用户在具备资格的情况下采取不同的行动姿态（即刻申请、条件跟踪、市场观测）。
- **语义模型清晰**：Daily Digest 与交互界面能够清晰分别呈现“资格是否符合”与“建议当前如何行动”，消除用户认知混淆。

### 约束与成本

- 数据模型与报告渲染层需分别承载资格结论与行动意图，增加了状态字段的表达维度。
- Agent 在进行语义研判时，需分别输出资格判定与行动意图裁决，需保持两阶段语义决策的独立性。
