# 高校与职校第一方及聚合招聘信息源摸底与抓取特征调研报告

> **关联工单**：[#2 高校与职校第一方及聚合招聘信息源摸底与抓取特征调研](https://github.com/carllx/career-radar/issues/2)  
> **研究目标**：摸底广州及珠三角高校与职校招聘信息发布体系、页面技术特征、附件解析痛点及从聚合源回溯第一方官方公告的方法。

## 1. 广州及珠三角院校招聘信息发布体系与结构

珠三角地区高校与职业院校的招聘信息发布呈现典型的“双轨制”与“多层级”结构：

```
                    ┌───────────────────────────────┐
                    │     上级主管部门/法定发布源     │
                    │ (广东省人社厅 / 广州市人社局)   │
                    └──────────────┬────────────────┘
                                   │ 编制审批/法定统招公告
          ┌────────────────────────┴────────────────────────┐
          ▼                                                 ▼
┌───────────────────────────────┐         ┌───────────────────────────────┐
│     公办高校/高职/技师学院     │         │      民办高校 / 独立学院       │
│ 第一方人事处官网 / 自建招聘系统 │         │  人事处官网 / 邮箱 / 商业招聘网 │
└──────────────┬────────────────┘         └──────────────┬────────────────┘
               │ 转载/抓取                               │ 合作发布/转载
               └───────────────────┬─────────────────────┘
                                   ▼
                    ┌───────────────────────────────┐
                    │       第三方聚合发现平台       │
                    │  (高校人才网 / 中国教师招聘网)  │
                    └───────────────────────────────┘
```

### 1.1 第一方发布体系（权威源头）
1. **省/市两级人社主管部门（事业编制法定发布源）**：
   - **广东省人力资源和社会保障厅**（[hrss.gd.gov.cn](http://hrss.gd.gov.cn/zwgk/gsgg/)）：发布省属公办本科（如华工、广工、华师等）、省属高职（如广轻大等）及省属技师学院的公开招聘与全省集中统招公告。
   - **广州市人力资源和社会保障局**（[rsj.gz.gov.cn](http://rsj.gz.gov.cn/ywzt/rszdgg/sydwzp/sydwzpgg/)）：发布广州市属高校（如广州大学、番禺职业技术学院等）的事业单位招聘公告。
2. **高校第一方官网与独立招聘系统**：
   - **公办本科**：人事处门户通知 + 独立招聘系统（如广大 `zp.gzhu.edu.cn`、深大 `zp.szu.edu.cn`）。
   - **公办高职 / 职业本科**：事业单位统招批次（依托人社系统）+ 学校自主用工招聘（人事处挂网公告，依托全国事业单位招聘网 `qgsydw.com` 或校内系统）。
   - **民办本科 / 独立学院**：完全自主用工，在学校人事处官网或商业平台发布，采用邮箱投递或商业招聘 SaaS。
   - **公办技师学院**：直属省/市人社部门，人事公告必须在人社厅局与学校官网双重挂网。

### 1.2 聚合发现体系（情报前哨）
- **高校人才网**（[gaoxiaojob.com](https://www.gaoxiaojob.com/)）：覆盖度最高的专业垂直平台，按省份、院校层次、专业分类。
- **中国教师招聘网**（[jiaoshi.com.cn](https://www.jiaoshi.com.cn/)）/ **学术桥**（[acabridge.edu.cn](https://www.acabridge.edu.cn/)）。
- **全国事业单位招聘网**（[qgsydw.com](https://www.qgsydw.com/)）：主要汇聚编制统招与事业单位招考。

## 2. 各渠道页面技术特征与抓取难点

| 渠道类型 | 代表站点 | 页面渲染架构 | 字符编码 | 反爬机制与防护边界 |
| :--- | :--- | :--- | :--- | :--- |
| **省级人社厅** | 广东省人社厅 | 服务端静态 HTML (`.html`)；列表含部分 Ajax | UTF-8 | 部署政务云 WAF（知道创宇/阿里云云盾）。限制高频并发，常规低频 GET 无验证码。 |
| **市级人社局** | 广州市人社局 | 服务端静态化 HTML 发布 | UTF-8 | 具备政务 WAF 与访问限频。静态内容直接可读。 |
| **公办高校人事处** | 广大、广工、华师人事处 | 高校站群 CMS 生成的纯静态 HTML | UTF-8（少数老旧系统为 GBK） | 基本无反爬与验证码；海外 IP 访问较慢或偶有阻断。 |
| **高校自建招聘系统** | 广大、深大招聘系统 | 前后端分离 SPA（Vue/React + REST API） | UTF-8 | 部分学校公开职位无需登录；部分具体投递需统一认证。 |
| **商业聚合平台** | 高校人才网 | SSR + 现代 Web 混合架构（Nuxt/Vue） | UTF-8 | 商业反爬（阿里云盾、频率风控、滑块验证码）。直接高频爬取易封禁。 |

## 3. 招聘公告发布特征与附件解析关键

### 3.1 发布周期与规律
- **春秋统考**：上半年（3-5 月）广东省事业单位集中公开招聘；下半年（9-11 月）秋季校园招聘与高层次人才引进。
- **自主/常态化招聘**：工作日滚动发布（多集中在上午 9:00-11:00 与下午 15:00-17:00）。

### 3.2 岗位明细表的核心载体（HTML 正文 vs 附件）
- **HTML 正文**：通常仅阐述宏观流程（单位介绍、政治条件、报名时间、网址入口、考核程序）。
- **附件文档（DOCX / XLSX / PDF）**：
  > [!IMPORTANT]
  > **80% 以上的事业编制及专任教师招聘中，核心结构化数据（岗位代码、具体专业名称、学历学位门槛、年龄限制、加试要求）均存放在公告文末的附件表格中（如《岗位需求表.xlsx》），而非直接写在 HTML 正文中。**
- **数据抓取启示**：仅抓取 HTML 标题与正文只能获得事件通知，精准匹配必须依赖附件下载与文档解析能力。

## 4. 聚合源在 Career Radar 中的定位与第一方回溯机制

### 4.1 定位：线索发现探测器（Sentry）
- 聚合平台仅作为“广度感知与快速发现”的触发器，严禁直接作为最终事实依据或简历投递目标，防止二手转载失真与滞后。

### 4.2 从聚合线索回溯第一方官方公告的三层机制
1. **第 1 层：显式来源提取**：解析页面底部“来源：XX人事处/人社厅”，抽取指向 `edu.cn` 或 `gov.cn` 的超链接。
2. **第 2 层：报名系统特征提取**：提取正文中的官方报名系统网址（如 `zp.gzhu.edu.cn`、`sydwbk` 等）。
3. **第 3 层：实体+文号精准回溯**：提取“招聘机构全称 + 公告标题/文号”，调用搜索引擎限定 `site:edu.cn OR site:gov.cn` 检索命中权威官方源。
