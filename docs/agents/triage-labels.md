# Triage Labels

工程技能基于 5 种规范的 Triage 角色进行工作。本文件将这些角色映射到本项目 Issue Tracker 中实际使用的标签字符串。

| Matt Pocock 规范标签 (`mattpocock/skills`) | 本项目实际标签 (`our tracker`) | 含义说明                                  |
| ------------------------------------------- | ------------------------------- | ----------------------------------------- |
| `needs-triage`                              | `needs-triage`                  | 维护者需要评估该 Issue                    |
| `needs-info`                                | `needs-info`                    | 正在等待提交者提供更多信息                |
| `ready-for-agent`                           | `ready-for-agent`               | 规格明确完备，可供 AFK Agent 独立执行     |
| `ready-for-human`                           | `ready-for-human`               | 需要人工实现或决策介入                    |
| `wontfix`                                   | `wontfix`                       | 不予处理或关闭                            |

当某个技能提及某个角色时（例如“添加 AFK-ready triage 标签”），使用上表对应的标签字符串。

后续若修改标签方案，请编辑本表右侧对应列。
